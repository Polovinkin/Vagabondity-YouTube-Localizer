Local-first YouTube localization

YT Localizer is a free-to-use, source-available tool for translating YouTube video titles and descriptions on your own computer.

It's available to use - and you don't need to register, log in to any third-party site or pay for another subscription. Follow the setup instructions on GitHub to set the app up. This website with detailed guides and walkthroughs is still in development.
